# Route Planner

Recrea la aplicación "Mis Rutas de Reparto" a partir del código adjunto (index.html, app de una sola página en HTML/CSS/JS vanilla, PWA para gestión de rutas de reparto con navegación por pestañas). Replica exactamente toda la lógica funcional existente (pestañas de navegación, gestión de rutas, paradas/clientes, estados, cualquier CRUD, cálculos, almacenamiento de datos, flujos, etc.) pero construye la interfaz completamente desde cero con un enfoque de diseño moderno y limpio: componentes responsivos que funcionen bien en móvil y escritorio, tipografía y espaciados cuidados, y un modo oscuro elegante como tema principal (manteniendo también buen soporte de modo claro si aplica). No te limites a portar los estilos del CSS original, rediseña la jerarquía visual, navegación y componentes (tarjetas, listas, botones, formularios, modales) usando buenas prácticas de UI moderna.
